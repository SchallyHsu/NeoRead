# 在两台电脑上使用 NeoRead 阅读和续聊

## 使用原生 Agent

在 **设置 → Agent → 阅读侧栏助手** 中选择 Claude Code、Codex、Antigravity 或 DeepSeek Harness。先安装 Node.js 24.9 或更新版本，以及所选助手的 CLI，并在该 CLI 完成登录。程序不在 PATH 中时填写可执行文件的绝对路径，例如 Windows 的 `agy.exe` 或 `dsh.cmd`。

填写项目名称和工作目录，点 **保存对话设置**。要和 Zotero 插件里的会话归入同一个项目，使用相同的项目名称和实际目录。打开 PDF 或 EPUB，在右侧提问。原生模式使用该助手的默认模型，接收问题、阅读位置、摘录、历史以及后端支持的图片。NeoRead 的全文工具、联网检索和翻译仍由内置模型连接提供。

| 助手 | 项目归属 |
| --- | --- |
| Claude Code | 按实际工作目录保存，使用 Claude Code 的本机项目历史。 |
| Codex | 通过 app-server 登记项目和会话。桌面侧栏首次登记可能需要完全退出并重开 Codex。 |
| Antigravity | 安装 App 和 agy 后可在原生项目创建会话，有 CLI 时也可单独聊天。 |
| DeepSeek Harness | 使用 dsh 的 ACP 会话。首次登记会启用旧插件配套的工作区扩展，完全退出并重开 dsh Desktop 或 Web 宿主后，工作区接收排队的会话。 |

侧栏保留已完成的回答。客户端登记失败或等待重启时，侧栏显示状态，下一轮回复后再检查。在本机续聊会复用可用的原生会话。另一台电脑用同步来的消息建立自己的原生会话。首次运行 Claude Code 或 Codex 需要联网安装版本固定的 ACP 桥接程序。应用处理助手的权限询问时会拒绝额外授权。

## 连接已有 WebDAV 主机

1. 两台电脑都运行本整合版，连接原来访问常开主机所用的网络或 VPN。
2. 打开 **设置 → 论文库（或图书库）→ 跨设备同步**。填写旧 Zotero Agent 聊天同步设置使用的现有 WebDAV 目录地址、用户名和密码，勾选同步，点击 **保存并同步**。密码存入本机的系统凭据库。
3. 在 A 机导入一份 PDF 或 EPUB 并完成一轮提问。在 B 机同步后打开同一文献和会话，可阅读并继续提问。每台电脑独立选择、安装和登录所用的 Agent。
4. 应用打开时约每分钟检查一次，两台电脑也可手动点 **保存并同步**。离线期间的文件和消息在重新连接后补传。

服务端使用 `neoread-v1/` 子目录，原文件按 SHA-256 去重，下载后核验并走 NeoRead 的正常导入流程。聊天按会话和问答轮次保存；同时离线续写会保留两端的问答。主机上原有的 Zotero 附件和 `zotero-agent-chat/v1.json` 可继续由原插件使用。NeoRead 同步的内容包括 PDF、EPUB、书库分类（论文或图书）、初始标题、会话名称及聊天记录。批注、独立附件、阅读进度、译文和本机 Agent 凭据不在本次同步范围内。

这是保留历史副本的增量同步。删除文献或会话只影响执行删除的设备。单份原文件上限 512 MiB，单轮聊天同步记录上限 16 MiB。

在一台同时运行两款软件的桌面电脑安装[配套 Zotero 扩展](../integrations/zotero-sync/README.md)，可以交换个人文库的 PDF、EPUB 和按论文保存的问答。有索引的 Zotero 原附件可通过已有 ZIP 读取。移动端使用已配置的 Zotero 查看论文，使用私有 WebDAV 的 `zotero-agent-chat/read.html` 查看聊天。
